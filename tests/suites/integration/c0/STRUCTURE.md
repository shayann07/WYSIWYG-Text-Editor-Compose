# Server-ordered structural compatibility trial

`ordered-structure.mjs` reuses the untouched frozen tree helpers from `validation/codex/run-20261016-20`. It checks their hashes against the historical manifest and writes evidence only into a new local-evidence directory. It does not run the historical verifier or overwrite its reports.

The private authority accepts stable-ID intents in a defined server sequence. It validates a staged copy before publishing one canonical bundle. Two readonly replicas buffer reordered/duplicate accepted packets and apply each complete transaction atomically. Initial snapshots are allowed; ordinary insertion packets must touch unit arrays rather than replace a whole flow/document. JSON-path packets are an experimental resolved transport, not a production canonical schema.

The bundle includes body/list/quote structure, rich table-cell flows and auxiliary header/footer specimens. These auxiliary wrappers are experimental S0 mapping, not a migration of the old production schema. Split gaps use the frozen Unicode helpers. Comment targets retain original unit IDs/context and become explicit orphans when their flow/content disappears.

Per-user history uses selective semantic inverses, never prior-root restoration across peer changes. Insert Undo removes its own units while preserving peer units inside the span. Formatting inverses respect field ownership, including same-value peer intent. Split/list inverses merge live peer text and preserve owned ancestry; Redo recreates retained identities against current anchors. New peer relocation/ancestry/content can produce a typed conflict with retained intent rather than silently overriding it.

Deleted-unit preimages are owner-controlled retained state. A reproduced format/delete/Undo counterexample showed why an old immutable delete payload alone is insufficient: A's undone style returned when B restored the deleted text. The trial now applies formatting inverses to retained units too, so restoration uses their current semantic attributes. This is implementation state, not an altered observed snapshot or oracle.

The generated lane runs 20 deterministic seeds with 500 actual canonical mutations each, separately from the existing 100,000-unit trial. It covers insert/delete/format/split/join/move, validates publications, checks unrelated raw units/attributes, and compares reordered/duplicate replicas. Rejected/no-op attempts are counted separately. Counts alone do not qualify the algorithm.

Full-copy staging, an in-memory role stub/history and experimental transport are deliberate feasibility limits. Crash-durable allocation/logs, compaction/inverse leases, real authentication, native composing-range admission, production Kotlin owner integration, broader structural conflicts and performance remain open. The C0 gate and algorithm selection remain open even when every bounded trial passes.

`queue-progress.mjs` covers the readonly queue's entry and serialized UTF-8 byte caps independently (default 256 entries / 8 MiB; test limits can be smaller). A reproduced defect refused the missing first packet when 256 later packets filled the queue. A next-in-sequence packet now applies directly without an extra queue slot and drains the waiting stream. Overflow instead records the highest observed required frontier and stops application; it does not discard uncertainty and resume from a guessed basis. An explicit validated snapshot must cover that frontier and wait until composition is safely released. Snapshot rejection is atomic; pending future packets survive resynchronization. Conflicting copies of a buffered sequence cannot silently replace its first payload. These caps measure serialized queue payload, not total JS heap or snapshot memory. The actual JVM owner case separately checks overflow recovery without clobbering accepted input.

Grouped authored commands resolve their flow by command type, including both join endpoints and the affected subtree for moves/deletes. Unsupported or ambiguous grouped commands refuse with retained intent. A header gesture cannot silently acquire a table-cell edit, including as a later child of an atomic batch. Legitimate cell joins still round trip through grouped selective Undo/Redo. Separately, suffix restoration tracks earlier units restored into the same captured gap so a shared surviving left anchor cannot reverse Urdu text on Redo. Both defects have preserved failing sources and exact regressions.

The durable adapter supplies a producer origin separate from actor attribution. Origin-aware history requires an explicit origin for Undo/Redo/discard; it does not silently widen to the whole actor. New edits abandon only that producer's Redo. Closed gesture metadata cannot be changed by another terminal command. A same-author/two-producer resource case keeps one canonical payload pinned until both scoped histories explicitly release it. Legacy single-producer-per-actor reference trials retain their original calling convention. None of this provides production device authentication/allocation or chooses a public history API.
