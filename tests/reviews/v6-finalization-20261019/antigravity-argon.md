#### Finding B1 (P0 — Spec Contradiction): Queued Composition Formatting + Partial Commit + Cancel Contradicts §4.6 vs. §4.7 / §4.12.2
* **Exact Section:** [Annex B §4.6](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1066) vs. [Annex B §4.7](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1074) and [Annex B §4.12.2](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1305).
* **Minimal Counterexample Trace:**
  1. Start with committed text `"Hello "` (`HistoryGroup #1`).
  2. Begin IME composition: `setComposingText("ab")` at offset 6.
  3. Execute `partialCommit(k = 1)`: `"a"` is accepted into $D_c$ at $[6, 7)$ under the active composition's `HistoryGroup #2`; `"b"` remains provisional in $\mathcal{O}$.
  4. While still composing `"b"`, user invokes `Format(Bold)` (queued as composition-target formatting) followed by `Undo`, `Undo`, `Undo`.
  5. IME cancels the remaining composition (`abortProvisional` / `finishComposingText(cancel)`).
* **Violated Contract & Evidence:**
  * [Annex B §4.7](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1074) states: *"Composition formatting targets the semantic constituent islands plus accepted session portions, never the convex hull and never untouched bridged text... Accepted surviving session text remains the target."*
  * [Annex B §4.12.2](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1305) states: *"A composition-target format whose final semantic target is empty returns `Cancelled(TargetDeleted)` and emits one `CommandWithoutHistory` ledger credit."*
  * Because `"a"` was accepted via `partialCommit(1)`, the final settled semantic target of the composition session after `abortProvisional` is **non-empty** ($[6, 7) = \text{"a"}$). Under §4.7 and §4.12.2, `Bold` **must succeed** on `"a"` and record a durable `Format` history entry (`HistoryGroup #3`), so the three `Undo` operations undo: (1) `Bold` on `"a"`, (2) committed `"a"`, and (3) `"Hello "`.
  * Yet [Annex B §4.6 line 1066](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1066) normatively dictates the exact opposite for this trace: *"For the trace `Hello ` -> preedit ab -> partial a -> queue Bold, Undo, Undo, Undo -> cancel: Bold cancels, first Undo consumes its ephemeral slot, second undoes accepted a, third undoes prior Hello."*
* **Proposed Correction:** Decide and enforce one consistent rule across §4.6, §4.7, and §4.12.2:
  * **Rule (Recommended — preserves §4.7 / §4.12.2):** Queued composition-target formatting applies to the union of surviving committed islands from the session (`acceptedSessionRanges` + committed residual). It cancels with `Cancelled(TargetDeleted)` and emits a `CommandWithoutHistory` slot **if and only if** the union of accepted session ranges and final committed residual is empty (0 UTF-16 units). Update §4.6 line 1066 so that in the `partial a -> cancel` trace, `Bold` formats surviving `"a"` (creating a real history group), and the three `Undo` actions revert `Bold("a")`, then `"a"`, then `"Hello "`; add a separate trace where `preedit ab -> queue Bold, Undo -> cancel` (with **no** partial commit) cancels `Bold` and consumes the `CommandWithoutHistory` slot.
* **Acceptance Test:** Deterministic unit test executing both traces (`partialCommit("a") + queue(Bold, Undo, Undo, Undo) + abortProvisional()` and `noPartialCommit + queue(Bold, Undo) + abortProvisional()`) verifying exact post-settlement document text, formatting spans, and undo stack depth.

* **Exact Section:** [Annex B §4.4](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1005-L1023).
* **Minimal Counterexample Trace:**

  2. `setComposingRegion(1, 3)` + `setComposingText("AB")` $\rightarrow$ provisional island `"AB"` at $D_c[1..3)$.
  3. Disjoint retarget to $[4, 5)$ + `setComposingText("XY")` $\rightarrow$ overlay $\mathcal{O}$ spans $D_c[1..5)$ with visible units `"AB"` (provisional, length 2) + `"3"` (untouched bridge, length 1) + `"XY"` (active marked island, length 2, overlay-relative marked interval $[m_0, m_1) = [3, 5)$).

* **Violated Contract & Evidence:**
  * Because $k = 0$, no cut is made and `"AB3"` (length 3) remains in the overlay ahead of `"XY"`.
  * However, [§4.4 line 1020](file:///d:/Work/WYSIWYG-Text-Editor-Compose/docs/plans/v6/editor-v6-standalone.md#L1020) unconditionally states: *"The new marked interval is `[0, (oldM1-oldM0)-k)`, NOT based on the whole overlay length."*
  * Applying `[0, (oldM1 - oldM0) - k)` for $k = 0$ changes the marked interval from $[3, 5)$ (`"XY"`) to $[0, 2)$ (`"AB"`), silently teleporting the active IME preedit target onto a prior provisional island!

  * For $k > 0$, cutting at $q = m_0 + k$ commits all overlay segments prior to $q$ into $D_c$ and advances the overlay start $sc'$ to the cut boundary, so the residual of the active marked island is now at the start of the narrowed overlay and its new overlay-relative marked interval is $[0, (m_1 - m_0) - k)$.
* **Acceptance Test:** Multi-island composition test (`"AB"` + bridge `"3"` + active mark `"XY"` at $[3, 5)$) asserting that `partialCommit(0)` leaves `[m0, m1) == [3, 5)` and `partialCommit(1)` commits `"AB3X"` into $D_c$ while narrowing the overlay to `"Y"` with `[m0, m1) == [0, 1)`.
