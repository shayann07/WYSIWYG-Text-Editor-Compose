# Security policy

ComposeDoc is pre-release software. No production security or durability
certification is implied. Report vulnerabilities privately using this
repository's Security tab / private vulnerability reporting when enabled.
If that option is unavailable, contact @shayann07 through an available private
GitHub channel to arrange secure disclosure; do not post exploit details or
private documents in a public issue.

Include the affected commit, platform, minimal reproduction and impact.
Remove credentials and user content. Do not test against other people's files,
accounts or systems. The maintainer will coordinate remediation and disclosure;
there is no promised response SLA for this volunteer project.

Document parsers, resource decoding, recovery evidence, clipboard admission,
file conflicts and native input provenance are security-sensitive boundaries.
Keep dependencies pinned and disclose unsupported or untested targets.
